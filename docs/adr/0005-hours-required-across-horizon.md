# Hours required span today→deadline, not one week

Large tasks use `hours_required` (UI: “Hours to spend before deadline”) placed across the scheduling horizon from today through the deadline, including weeks reachable via prev/next navigation. Keeping a “this calendar week only” pool would make multi-week navigation cosmetic and understate available capacity before the deadline. The old names `weekly_hours_required` / `total_weekly_hours` are retired.
